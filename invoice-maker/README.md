# 🧾 手帐发票素材生成器

一款运行于浏览器的本地工具，帮助手帐爱好者快速生成仿真票据贴纸，无需安装、无需联网（品牌预设 Logo 除外），即开即用。

---

## ✨ 功能一览

### 发票类型（5 种）

| 类型 | 主色 | 额外字段 | 品牌预设 |
|------|------|----------|---------|
| 🍜 餐饮 | 红 | 桌号、服务员 | 盒马、奥乐齐、山姆、读酥世家 |
| 👗 服装 | 蓝 | 门店编号、收银员 | — |
| 🧴 日化 | 橙 | 门店编号、收银员 | — |
| 💻 数码 | 紫 | 订单号、保修期 | Apple、华为、小米、影石、大疆 |
| 🧋 茶饮 | 绿 | 门店、会员名 | 8 大茶饮品牌 |

### 可编辑信息

- **店铺名称**、**日期**、**时间**（均可留空）
- **消费平台**（淘宝 / 京东 / 抖音 / 拼多多 / 小红书 / 微信小程序 / 门店自提）
- **备注**（自提 / 堂食 / 外卖等）
- 各类型对应的**专属附加字段**（桌号、订单号等），不填则在发票中自动隐藏

### 商品明细

- 动态添加 / 删除商品行
- 每行支持：品名、数量、原价、优惠价
- 自动计算合计金额；有优惠时显示划线原价 + 优惠价，并汇总节省金额

### 额外费用 & 优惠

- 独立的**额外费用**行（运费、服务费等）
- 独立的**优惠信息**行（会员折扣、券减等）
- 均支持动态增删，留空则在发票中自动隐藏

### 店铺 Logo

- **自定义上传**：支持任意图片格式，保持原始宽高比显示
- **拖放上传**：直接将图片文件拖到 Logo 区域
- **Ctrl+V 粘贴**：截图后直接粘贴即可设置 Logo
- **品牌预设**（茶饮 / 餐饮 / 数码类型时显示）：
  - 茶饮：一点点、Manner、瑞幸、喜茶、奈雪、蜜雪冰城、淡马茶坊、霸王茶姬
  - 餐饮：盒马、奥乐齐、山姆、读酥世家
  - 数码：Apple、华为、小米、影石、大疆
  - 优先加载 Clearbit 官方 Logo，网络不可用时自动回退为内嵌 SVG

### 输出尺寸

| 尺寸 | 物理规格 | 保存图片像素（300dpi） |
|------|---------|----------------------|
| A7 | 74 × 105 mm | 874 × 1240 px |
| A7-sp | 80 × 120 mm | 945 × 1417 px |
| **A6**（默认）| 105 × 148 mm | 1240 × 1748 px |
| A5 | 148 × 210 mm | 1748 × 2480 px |

### 导出方式

- **⬇ 保存图片**：按所选纸张尺寸以 300 dpi 导出高清 PNG
- **📋 复制**：直接复制发票图片到剪贴板（Chrome / Edge / Safari 支持）
- **🖨 打印**：弹出打印窗口，`@page` 自动设置为对应纸张尺寸

## 🚀 使用方法

1. 用任意浏览器（推荐 Chrome / Edge / Safari）打开 `invoice-maker.html`
2. 在左侧面板填写信息，右侧实时预览发票效果
3. 选择输出尺寸后点击"保存图片"、"复制"或"打印"

> **无需服务器**，直接双击 HTML 文件即可运行。

### 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + S` | 保存图片（PNG） |
| `Ctrl/Cmd + V` | 粘贴图片作为 Logo |

---

## 📱 移动端支持

- 顶部"✏️ 编辑 / 👁 预览"切换标签
- 操作按钮固定在屏幕底部，随时可用
- 输入框与按钮均放大至触控友好尺寸（≥ 44px）
- 超小屏幕（≤ 360px）自动缩放发票预览

## 💡 使用提示

- 切换发票类型时，店铺名称和示例商品会自动更新为对应默认值
- 所有"选填"字段留空时，发票中对应行**自动隐藏**，不留空白
- 时间字段留空时，发票中只显示日期
- 每次切换发票类型会生成新的随机单号
- 导出文件名格式：`发票-{店铺名}-{尺寸}-{日期}.png`
- 草稿自动保存到 `localStorage`，刷新后恢复上次编辑内容
